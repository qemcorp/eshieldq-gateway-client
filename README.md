# eShield-Q Gateway — Python Client

Python client for the eShield-Q Gateway REST API. Handles login, session
cookies, MFA and mutual TLS, so you work with the API rather than with HTTP.

```bash
pip install eshieldq-gateway-client
```

The request and response models come from
[`eshieldq-gateway-schemas`](https://github.com/qemcorp/eshieldq-gateway-schemas),
which is installed as a dependency.

The user guide, including a worked example for each area of the API, is in
[`eshieldq-gateway-docs`](https://github.com/qemcorp/eshieldq-gateway-docs).

Version **4.1.52**. See [SECURITY.md](SECURITY.md) to report a vulnerability.
